## 〇、一句话总纲

> **同一个图形，先认出来，再量出来，最后动起来。翻页顺序是螺旋，知识本体是三条直线。**

12 册里"图形"出现过十几次，其实只有三件事各走了三遍：

| 线 | 一句话讲法 | 每次升级升的是什么 |
|---|---|---|
| **认识** | 它是什么样 | 特征越来越准、分类越来越严（实物 → 平面 → 角 → 三角形四边形 → 圆 → 圆柱圆锥） |
| **度量** | 它有多大 | 量什么 / 用什么单位 / 为什么是这个单位（长度 → 角 → 周长 → 面积 → 体积 → 圆的度量） |
| **运动** | 它怎么变 | 从"看形状变了"到"看什么没变"（图形的变化 → 图形的运动 → 轴对称平移 → 旋转） |

三条线的关系：**认识给对象，度量给数，运动给关系。** 讲课时不必按册翻，按线串。

## 一、逐册大纲（只列属于本线的单元）

### 低年级（1—2 年级）：命名 + 给长度定规矩

**一年级上册**
- **六 认识图形**（认识｜起点）
  - 讲什么：只做一件事——**摸与认**。长方体、正方体、圆柱、球，全是"体"。
  - 怎么讲：鞋盒、魔方、易拉罐、皮球各来一个，滚一滚、推一推、摞一摞，按"能不能滚、有几个平平的面"分类。不要定义，要"叫得出、分得开"。
  - 易错：把"正方体"叫成"正方形"、把"球"叫成"圆"。**从这一课起就把"体/形"两个字分开念。**
  - 锚点：「这样的是**体**。」
- **五 位置与顺序**（认识｜铺垫）
  - 上下、前后、左右。给 1 下「观察物体」预备方位语感，不必当图形课讲。

**一年级下册**
- **二 观察物体**（认识｜第 1 遍，单元名 OCR 未清，按教材常规）
  - 从不同方向看同一个物体，看到的样子不同。四个年级会出现四遍，**用同一组积木模型贯穿**。
- **四 有趣的图形**（认识）
  - 讲什么：平面图形——长方形、正方形、三角形、圆。
  - 怎么讲：由立体"印"出平面（印一印、描一描）。第一句话就是**「面在体上」**。
  - 前连后接：1 上·六 认识图形（立体）→ 1 下·四 有趣的图形（平面），一次课连讲。

**二年级上册**
- **六 测量**（度量｜**度量线的起点**）
  - 讲什么：厘米、米。
  - 怎么讲：先制造困境——"用铅笔量、用手量，为什么会吵架？"逼出"要有一根人人一样长的尺子"。
  - 易错：不从刻度 0 起量；**断尺量法**（从刻度 3 量到 8，是 5 厘米，不是 8 厘米）。
  - 锚点：「量长度，要先有**单位**。」
- **四 图形的变化**（运动｜内容待核，目录仅给单元名）

**二年级下册**
- **四 测量**（度量）
  - 分米、毫米、千米。长度单位家族成形：毫米 < 厘米 < 分米 < 米 < 千米，相邻进率 **10**（米→千米为 1000）。
- **六 认识图形**（认识）
  - 认识角：直角、锐角、钝角。
  - 易错：**角的大小与边画的长短无关**——用活动角、剪刀张口演示。这是全小学最顽固的一个错。

### 中年级（3—4 年级）：线的长度、面的角、周长与面积

**三年级上册**
- **二 观察物体**（认识｜第 2 遍）
- **五 周长**（度量｜**★关键对比一 的一半**）
  - 讲什么：**一条线**——封闭图形一周的长度。长方形 C=2(a+b)，正方形 C=4a。
  - 怎么讲：用绳子沿边绕一圈，再拉直去量。一句话锚点：**「周长是一条线。」**
  - 易错：与面积混用；拼合后周长会变（两个正方形拼成长方形，少了 2 条边）。

**三年级下册**
- **二 图形的运动**（运动｜第 2 遍）
- **五 面积**（度量｜**★关键对比一 的另一半**）
  - 讲什么：**一个面**——物体表面或封闭图形的大小。面积单位 cm²、m²；长方形 S=ab，正方形 S=a²。
  - 已核对：教材用 1 平方厘米小纸片去铺 1 平方分米的大正方形，得出 **1 平方分米 = 100 平方厘米、1 平方米 = 100 平方分米**（PDF 第 60 页）。
  - 怎么讲：与周长对讲。同一张纸，"**框**"是周长，"**铺满**"是面积。
  - 易错：**面积相邻单位进率是 100，不是 10**（与长度不同，必须专门强调）。
  - 锚点：「周长是一条线，面积是一片面。」
- **四 千克、克、吨**（度量｜旁置）
  - 结构上同属"度量"：我们量过线、量过面，现在量"重量"。顺带讲"量什么用什么单位"。

**四年级上册**
- **二 线与角**（度量 + 认识）
  - 直线/射线/线段；角的度量（度）与量角器；锐角、直角、钝角、平角、周角。
  - 易错：量角器有两圈刻度，读错极其常见；再次强调角的大小与边长无关。

**四年级下册**
- **二 认识三角形和四边形**（认识）
  - 三角形按角/按边分类；**内角和 180°**；三边关系；平行四边形与梯形的特征与高。
  - 怎么讲：把三个角撕下来拼成一个平角，验证内角和。
  - 易错：**底与高必须互相垂直**；平行四边形有两组底和高。
- **四 观察物体**（认识｜第 3 遍）

### 高年级（5—6 年级）：面、体、圆、柱锥

**五年级上册**
- **二 轴对称和平移**（运动）
- **四 多边形的面积**（度量｜**转化思想的核心单元**）
  - 已核对：单元首节就是**「比较图形的面积」**，用**分割、移补**说明"图形变了、面积没变"——这就是全单元的钥匙（PDF 第 53 页）。
  - 讲什么：平行四边形、三角形、梯形面积公式，但真正要讲的是**转化**。
  - 怎么讲：所有公式都从长方形推出来。平行四边形→剪拼成长方形；三角形→两个拼成平行四边形；梯形→两个拼成平行四边形。**抓住"转化"，三个公式不用背。**
  - 易错：底高不对应；三角形与梯形公式里的 ÷2 是"两个拼一个"的记账。
- **六 组合图形的面积**（度量｜印刷页 88）
  - 分割法 / 添补法，是对"转化"的第二次练习。

**五年级下册**
- **二 长方体（一）**（度量｜**★关键对比二**）
  - 已核对：首节「长方体的认识」，面/棱/顶点，并明确讨论"**正方体是特殊的长方体吗**"（PDF 第 15 页）。
  - 讲什么：展开图、表面积。
  - 怎么讲：表面积 = 把立体"展开成一张纸"求面积。拿真盒子剪开，孩子自己数出六个面。
- **四 长方体（二）**（度量｜**★关键对比二**）
  - 讲什么：体积与容积，cm³ / dm³ / m³，长×宽×高，1 dm³ = 1 L。
  - 怎么讲：体积 = 往里面**塞 1 cm³ 小方块，数有多少个**。与表面积并排对比"面"与"体"。
  - 易错：cm² 与 cm³ 混；容积与体积的差别（容器壁厚）；体积相邻进率 **1000**。

**六年级上册**
- **一 圆**（认识 + 度量）
  - 已核对：首节「圆的认识（一）」从"**套圈游戏公不公平**"引入，得到圆心、半径、直径与 **d = 2r**（PDF 第 6 页）。
  - 讲什么：圆的周长 C=πd=2πr；圆的面积 S=πr²（化圆为方：剪拼成近似长方形）。
  - 怎么讲：**让孩子自己用绳子量"周长 ÷ 直径"≈3.14**，把圆周率做成一次发现，而不是给一个公式。
  - 易错：周长与面积公式混（2πr 与 πr²）；半圆周长还要加直径。
- **三 观察物体**（认识｜第 4 遍）

**六年级下册**
- **一 圆柱与圆锥**（度量｜**收官**）
  - 已核对：本章练习就是"立体图形展开图求表面积""圆柱形钢柱""粮仓容积"等实际问题（PDF 第 18 页）——**6 下开篇就在复用 6 上的圆**。
  - 讲什么：圆柱表面积 = 两个底面圆 + 侧面展开成长方形；圆柱体积 = 底面积 × 高；圆锥体积 = 等底等高圆柱的 1/3。
  - 怎么讲：圆柱体积就是 5 下"底面积×高"的直接推广（所有直柱体统一）；圆锥的 1/3 用**等底等高倒水实验**验证。
  - 易错：圆锥忘 ÷3；侧面积与表面积混（题目要不要加两个底面）。
- **三 图形的运动**（运动｜第 3 遍，旋转）

## 二、三条螺旋升层表

| 主题 | 第一层（1—2 年级） | 第二层（3—4 年级） | 第三层（5—6 年级） |
|---|---|---|---|
| **认识** | 立体/平面的命名（1 上·六、1 下·四） | 角、三角形四边形的特征与分类（2 下·六、4 下·二） | 圆的特征、圆柱圆锥（6 上·一、6 下·一） |
| **度量** | 长度单位：厘米米 → 分米毫米千米（2 上·六、2 下·四） | 角（4 上·二）、周长（3 上·五）、面积（3 下·五） | 多边形面积（5 上·四）、体积（5 下·四）、圆的度量（6 上·一） |
| **运动** | 图形的变化（2 上·四） | 图形的运动（3 下·二）、轴对称和平移（5 上·二） | 旋转（6 下·三） |
| 贯穿·观察物体 | 1 下·二 | 3 上·二、4 下·四 | 6 上·三 |

## 三、度量链（本线主轴）

```
长度(2上/2下) → 角(2下/4上) → 周长(3上) → 面积(3下) → 多边形面积(5上) → 体积(5下) → 圆(6上) → 柱锥(6下)
```

三句话：
1. **长度 → 面积 → 体积 是同一个动作重复三遍**：都是用单位去铺，只是铺在线上、面上、体里。
2. **进率随维度变**：长度相邻 ×10，面积相邻 ×100，体积相邻 ×1000——因为面积是两条边同时放大 10 倍（10×10），体积是三条边（10×10×10）。
3. **公式不是背的，是数单位个数数出来的**：面积和体积公式都能从长方形出发推出来。

## 四、★ 三次关键对比（全大纲最值得停下来的地方）

1. **线 vs 面**：3 上·五 周长 ↔ 3 下·五 面积。同一张纸，"框"与"铺"。
2. **面 vs 体**：5 下·二 表面积 ↔ 5 下·四 体积。同一个盒子，"展开"与"塞满"。
3. **形变 vs 量变**：拉一拉、剪一剪——**形状变了，什么没变？**（5 上·四 首节"分割移补"+ 长方形拉成平行四边形）

## 六、易错清单（附一句纠正）

| 易错 | 一句纠正 |
|---|---|
| 周长、面积不分 | 周长是一条线，面积是一片面。 |
| 把长度单位当面积单位 | 面积单位 = 长度单位前加"平方"，厘米 → 平方厘米。 |
| 进率混用 | 长度相邻 ×10，面积 ×100，体积 ×1000：因为面有两条边、体有三条边同时放大。 |
| 角的大小看边长 | 角的大小只看张口，与边画多长无关。 |
| 底与高不对应 | 高必须垂直于所画的底；平行四边形有两组底和高。 |
| 三角形/梯形面积忘 ÷2 | ÷2 是"两个拼一个"的记账。 |
| 圆锥体积忘 ÷3 | 等底等高的圆锥，倒三次水才灌满圆柱。 |
| 半圆周长漏直径 | 半圆周长 = πr + 2r，不是 πr。 |
| 以为拉一拉面积不变 | 长方形拉成平行四边形：周长不变，面积变小（高变小）。 |
| 把正方体叫正方形 | 一年级起就把"体"和"形"分开念。 |

## 七、可以问孩子的问题（检验理解，不考记忆）

1. 用同样长的绳子围长方形，面积能一样吗？
2. 两个正方形拼成一个长方形，周长变了吗？面积变了吗？
3. 把长方形框拉成平行四边形，周长、面积谁变？
4. 圆柱的体积公式和长方体有什么关系？
5. 面积单位为什么是 100 进率，长度却是 10？
6. 1 平方米等于多少平方厘米？
7. 三角形的面积为什么要除以 2？
8. 圆周率 3.14 是背下来的还是一个固定的事实？
