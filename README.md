# 学习馆 · Kids Study

自己动手做的儿童互动课程：**能点、能玩、能做题**。整站是纯静态单文件网页——没有后端、不注册、不收集数据，学习进度只存在访问者自己的浏览器里。

> 线上地址：https://moneyache.github.io/kids_study/

## 现在有什么

### 📐 数学 · 图形与几何（已上线）

按北京师范大学出版社《义务教育教科书·数学》的编排顺序整理的「图形与几何」主线：
从认识立体图形出发，一路走到长度、角、周长、面积、体积、圆。

| 入口 | 给谁用 | 内容 |
|---|---|---|
| `math/course.html` | 孩子 | **互动课堂**：10 课、27 道即时判题、13 个可动手小实验。答错给提示、不扣分；★ 只记「第一次就答对」的题 |
| `math/outline.html` | 老师 / 家长 | **教师版**：逐册讲解大纲、三条螺旋升层表、跨册串联、7 个讲授模块、10 条易错清单、8 个检验理解的问题 |
| `math/outline.md` | — | 教师版大纲的 Markdown 源文（方便复制到别处） |

互动课堂的 10 课：

1. 认识立体图形（长方体 / 正方体 / 圆柱 / 球）
2. 面在体上（描面 → 长方形 / 正方形 / 三角形 / 圆）
3. 长度和单位（为什么要有尺子；厘米、米，相邻 ×10）
4. 角：只看张口（角的大小与边长无关）
5. 周长是一条线（沿着边走一圈）
6. 面积是一片面（铺 1 cm² 小方格；进率 100）
7. 形状变了，什么没变（剪拼转化、拉一拉）
8. 体积是一个体（塞 1 cm³ 小方块；底面积 × 高；进率 1000）
9. 圆：量出来的 3.14（滚一圈量周长）
10. 闯关：整条线走一遍（8 道混合题）

## 目录结构

```
/
├── index.html          学科门户（学习馆首页）
├── .nojekyll           让 GitHub Pages 原样发布（不跑 Jekyll）
└── math/               一个学科 = 一个目录
    ├── index.html      学科首页：两个入口 + 掌握程度统计
    ├── course.html     互动课堂（孩子用）
    ├── outline.html    教师版（老师 / 家长用）
    └── outline.md      大纲 Markdown 源文
```

## 加一个新学科

照着 `math/` 抄一份就行：

```
english/
├── index.html      学科首页（两个入口 + 进度统计）
└── course.html     互动课堂
```

学科首页的「掌握程度」是直接读 `localStorage` 里互动课堂的进度键（数学用的是 `geo-course-v1`，
结构为 `{ "L1": { done: true, first: {2:true}, solved: {2:true,3:true} } }`）。新学科换一个自己的键即可。

## 本地预览

纯静态，起个静态服务器就能看：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

也可以直接双击 `index.html`（`file://` 打开同样能跑，只是页面之间用相对路径跳转）。

## 部署

GitHub Pages，`main` 分支根目录，公开仓库。更新内容只要：

```bash
git add -A && git commit -m "update" && git push
```

Pages 会自动重新发布（约 1 分钟）。

## 关于内容与版权

- 课程的文字、图示、练习题、交互都是自己写的，按教材的**编排顺序**组织，便于和学校进度对齐。
- 本仓库**不包含**教材原文或扫描件。教材版权属北京师范大学出版社，本站仅作个人学习用途。
- 建议把它当"陪读工具"用：孩子先在互动课堂自己玩一遍，家长再用教师版的 8 个问题问一问，
  看哪一课还答不上来就回去重做那一课。
