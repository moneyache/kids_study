# 学习馆 · Kids Study

自己动手做的儿童互动课程：**能点、能玩、能做题**。整站是纯静态单文件网页——没有后端、不注册、不收集数据，学习进度只存在访问者自己的浏览器里。

> 线上地址：https://moneyache.github.io/kids_study/

## 现在有什么

### 📐 数学（4 个主题，已上线）

数学按**主题**拆成四门小课，每个主题都是「互动课堂（孩子用）＋ 教师版（老师 / 家长用）」的完整一套。
内容按北京师范大学出版社《义务教育教科书·数学》的编排顺序整理：

| 主题 | 课数 | 即时判题 | 小考卷 | 动手实验 | 目录 |
|---|---|---|---|---|---|
| **图形与几何** | 10 | 47 | 10 张（53 题） | 14 个 | `math/geometry/` |
| **数与数感** | 8 | 45 | 8 张（41 题） | 10 个 | `math/numbers/` |
| **数与运算** | 8 | 40 | 8 张（41 题） | 同上 | `math/calculation/` |
| **测量** | 11 | 56 | 11 张（56 题） | 8 个（另复用 3 个） | `math/measure/` |

每个主题目录里都是同样的三个页面：

| 文件 | 给谁用 | 内容 |
|---|---|---|
| `course.html` | 孩子 | **互动课堂**：一步一步点、边玩边学，每课学完一张 4—5 题的**小考卷**（立刻出成绩、列出错题）。答错给提示、不扣分；★ 只记「第一次就答对」的题 |
| `outline.html` | 老师 / 家长 | **教师版**，只做三件事：① 掌握程度（练习进度 / ★ / 小考成绩 / 还没答对的题清单）② 易错与提问 ③ 教学大纲 |
| `index.html` | — | 主题首页：两个入口 + 掌握程度总览 |

数学首页 `math/index.html` 是**主题 tab**：点标签切换主题，每个标签上带进度徽标。

37 课的内容：

- **图形与几何**（10 课，**课名照课本**）：认识图形（1上·六）→ 有趣的图形（1下·四）→ 长度和单位（复习）→ 认识图形·角（2下·六）→ 周长（3上·五）→ 面积（3下·五）→ 多边形的面积（5上·四）→ 长方体·体积（5下·二、四）→ 圆（6上·一）→ 闯关
- **数与数感**（8 课，**课名照课本**）：生活中的数：数一数（1上·一）→ 古人计数：11—20（1上·七）→ 数花生：100 以内（1下·三）→ 数一数（一）：一千有多大（2下·三）→ 数一数（二）：一万和亿（2下·三 / 4上·一）→ 比一比：先比位数 → 温度与正负数（4上·七）→ 数感闯关
- **数与运算**（8 课，**课名照课本**）：有几支·还剩下多少（1上·三）→ 有几瓶牛奶·有几棵树（1上·七）→ 买铅笔·捉迷藏·快乐的小鸭（1下·一）→ 采松果·摘苹果·谁的得分高（1下·五、六 / 2上·一）→ 有多少块糖·儿童乐园（2上·三）→ 做家务·需要几个轮子·有多少张贴画（2上·五、八）→ 分桃子·分香蕉·长颈鹿与小鸟（2上·七、九）→ 买文具·加法交换律·乘法分配律（4上·四）
- **测量**（11 课，**课名与顺序照课本**）：教室有多长 → 课桌有多长 → 练习一（量一量·画一画）→ 1 米有多长 → 练习二（填「厘米」还是「米」）→ 铅笔有多长（分米与毫米）→ 练习三（长度单位换算）→ 1 千米有多长 → 练习四（填单位·整理单位）→ 改一改：淘气的日记 → 量一量·比一比·闯关

> 每课学完会出一张**小考卷**，做完立刻给分数、星级和错题清单；错题会汇总到教师版的「掌握程度」里，家长一眼看到该补哪一课。

## 目录结构

```
/
├── index.html              学科门户（学习馆首页）
├── .nojekyll               让 GitHub Pages 原样发布（不跑 Jekyll）
└── math/                   一个学科 = 一个目录（以后 english/、chinese/ 同级）
    ├── index.html          数学首页：主题 tab 条
    ├── topics.js           主题清单（加主题只改这里 + 建一个目录）
    ├── assets/             共享引擎（所有主题共用，改一处全站生效）
    │   ├── course.css/js       互动课堂引擎（步骤 / 判题 / 本课小考 / 进度）
    │   ├── teacher.css/js      教师版引擎（掌握程度 / 易错与提问 / 教学大纲）
    │   ├── topic.css/js        主题首页引擎
    │   ├── hub.js              数学首页（主题 tab）
    │   ├── widgets.geo.js      图形与几何的 14 个动手部件
    │   ├── widgets.num.js      数与运算的 10 个动手部件
    │   └── widgets.meas.js     测量的 8 个动手部件（测量主题额外复用 unit / ruler / ladder）
    ├── geometry/           主题一：图形与几何
    │   ├── index.html / course.html / outline.html
    │   ├── data.js             课程数据（window.COURSE_DATA）
    │   ├── teacher-data.js     教师数据（window.TEACHER_DATA）
    │   └── outline.md          大纲 Markdown 源文
    ├── numbers/            主题二：数与数感（同上结构）
    ├── calculation/        主题三：数与运算（同上结构）
    └── measure/            主题四：测量（结构同上）
```

四个主题目录里都各有一份 **`TEXTBOOK-NOTES.md`**：逐页记录该主题对应的课本单元、
印刷页→PDF 页的换算（12 册统一为 **PDF 页 = 印刷页 + 4**）、课本原题与题型清单。
课程内容与题目都按它编写，家长可以拿着课本一页页对。


⚠️ 每个主题的课程内容都在它自己的 `data.js` 里，页面本身只是外壳 —— 改内容只改数据，不用碰 HTML。

## 加一个新主题（数学下面）

1. 复制一个主题目录：`cp -r math/numbers math/<新主题>`
2. 改 `data.js` 的 `key`（新主题用新键，例如 `frac-course-v1`；进度靠它区分）、`title`、`lessons`
3. 改 `teacher-data.js` 的 `curriculum`（条数 / 题数要和 `data.js` 对得上）、`errors`、`questions`、`outlineHtml`
4. 在 `math/topics.js` 里加一条（`dir` / `key` / `emoji` / `title` / `desc`）—— 首页的 tab 就自动出现了

需要新的动手部件时，写进 `assets/widgets.num.js`（或另建 `widgets.<主题>.js`），
并在该主题的 `course.html` 里多引一行 `<script src="../assets/widgets.xxx.js"></script>`。

## 加一门新学科（英语、语文…）

顶层新建一个目录，照 `math/` 的形状写，再到门户 `index.html` 里加一张卡片：

```
english/
├── index.html      学科首页（主题 tab 或直接一个课程列表）
├── assets/         该学科自己的共享引擎（可复用 math/assets 那一套）
└── <主题>/
    ├── index.html / course.html / outline.html
    ├── data.js
    └── teacher-data.js
```

数学四个主题的进度键分别是 `geo-course-v1` / `num-course-v1` / `calc-course-v1` / `meas-course-v1`；新主题、新学科用新的键就不会互相覆盖。

## 本地预览

纯静态，起个静态服务器就能看：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

也可以直接双击 `index.html`（`file://` 打开同样能跑，只是页面之间用相对路径跳转）。

## 部署

GitHub Pages，`main` 分支根目录，公开仓库。更新内容只要：

```bash
git add -A && git commit -m "update" && git push
```

Pages 会自动重新发布（约 1 分钟）。

## 关于内容与版权

- 课程的文字、图示、练习题、交互都是自己写的，按教材的**编排顺序**组织，便于和学校进度对齐。
- 本仓库**不包含**教材原文或扫描件。教材版权属北京师范大学出版社，本站仅作个人学习用途。
- 建议把它当"陪读工具"用：孩子先在互动课堂自己玩一遍，家长再用教师版的 8 个问题问一问，
  看哪一课还答不上来就回去重做那一课。
